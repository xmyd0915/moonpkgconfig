# MoonPkgConfig 0.1.0 发布说明

0.1.0 是第一个可公开验证的版本。它提供保留源码位置的 `.pc` 解析、依赖检查和编译/链接参数查询，主要面向 MoonBit FFI、原生库接入、构建工具与 CI。

## 主要内容

- 解析变量、常用字段、注释、续行和常见文本边界，并保留文件、行、列位置；
- 检查必填元数据、依赖版本、缺失依赖、循环与冲突；
- 处理公开/私有依赖、动态/静态链接参数和 `Provides` 虚拟包范围；
- 输出带来源的参数说明、稳定 JSON 和明确退出码；
- 支持有序搜索目录、变量覆盖、搜索路径去重、显式系统目录过滤与 sysroot；
- 提供单文件检查、整目录检查和依赖查询三个 CLI 入口。

## 验证快照

- 59 个逻辑测试在 wasm、wasm-gc、JavaScript、native 四个目标下全部通过；
- 22 项行为与固定 pkgconf 3.0.7 自动差分；
- 11 个未经修改的 pkgconf 官方测试文件；
- zlib 1.3.1 与 libffi 3.4.6 固定上游模板；
- Windows 本地与 Ubuntu GitHub Actions 验证；
- 使用查询结果实际完成 C 静态库与 C++ 调用程序的编译、链接和运行。

## 已知边界

- 不自动读取系统 pkg-config 环境或默认搜索目录；
- 不实现 Windows 自动重定位、全部片段优化和所有 pkgconf 扩展；
- 参数文本使用 POSIX shell 引用，跨平台程序集成应读取 JSON 数组；
- MoonCakes 模块为 `xmyd0915/moonpkgconfig`，核心库可用 `moon add xmyd0915/moonpkgconfig@0.1.0` 安装。
