## 首次发布前需要维护者完成

1. 检查 `CHANGELOG.md`、版本号和 Git 工作区，推送发布版本。
2. 执行 `moon publish`，并核对公开页面。登录凭据不得进入仓库或验证记录。
3. 如有需要，再创建对应的 GitHub Release。

首次发布属于外部账号操作。如发布时提示命名空间不匹配，先核对 MoonCakes 账号名称再调整，避免发布到错误名称后再迁移。
